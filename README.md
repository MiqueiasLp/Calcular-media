# Sistema de Notas em Python

Um programa simples em linha de comando feito em Python para calcular a média de notas e verificar a situação final do aluno.

## Como usar

1. Execute o arquivo `main.py` no terminal.
2. Digite o nome do aluno, a quantidade de faltas e o número de notas.
3. Insira o valor de cada nota para ver a média e o resultado final.

## Estrutura do projeto

- `main.py` → lógica principal do programa (cálculo de notas e verificação)

## Regras de Aprovação

- **Aprovado:** Média >= 7.0 e até 5 faltas
- **Em Recuperação:** Média entre 5.0 e 6.9 e até 5 faltas
- **Reprovado:** Média < 5.0 ou mais de 5 faltas

## Tecnologias usadas

- Python 3
