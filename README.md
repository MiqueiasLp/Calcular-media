Sistema de Apuração de Média e Frequência do Aluno (Python)

Script em Python desenvolvido para automatizar o cálculo de médias escolares dinâmicas e determinar o status de aprovação de alunos com base nas notas inseridas e no limite de faltas.

Funcionalidades

- Cálculo de Média Dinâmica: Aceita qualquer quantidade de notas informada pelo usuário.
- Validação de Frequência: Avalia o impacto das faltas na aprovação.

Linguagem: Python
